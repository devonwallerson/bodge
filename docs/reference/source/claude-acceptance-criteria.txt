Acceptance criteria and build plan
How to use this plan
Each section below is one milestone from the build plan. It's done when every criterion in its table is marked Done and passes on both a phone and a desktop.
• One criterion, one check. Every row states an observable result and how to verify it. If you can't check it in under two minutes, split it.
• IDs are stable. Reference them in commits and PRs (feat: M2-04 re-answer from panel), so the history maps back to this plan.
• Status flow: Not started → In progress → Done. Mark a criterion Blocked if it's waiting on a decision, and add a comment saying what it's waiting on.
• Don't start the next milestone early. It can begin when the current one has no rows left in Not started.
Definition of done, inherited by every criterion:
[ ] Works at 390 px (a real phone) and at 1440 px (desktop Chrome)
[ ] Works in all five themes with no hard-coded colors
[ ] No console errors or TypeScript any in the touched code
[ ] Keyboard-only use works on desktop, and touch-only use works on mobile
[ ] Merged to main and deployed to the preview URL

MVP gate
The MVP ships when this script passes end to end on three devices in one sitting: a real iPhone (Safari), a real Android phone (Chrome) and a desktop (Chrome at 1440 px).
1. Open the production URL fresh, with cleared storage. The intro lines show and bodge is idle.
2. Type /help. The command list appears instantly.
3. Run /generateIdea and answer all five questions. Use touch on the phones and keys only on desktop, with at least one free-text answer.
4. Watch what bodge knows, in the side panel or the sheet, fill row by row.
5. Re-answer spice from the panel or sheet. Only that question is re-asked.
6. Ideas arrive. bodge goes thinking → typing → eureka, and the card reveals with no broken text.
7. Page to idea 2 by swiping or pressing ]. Accept it.
8. Refine the idea with "make it multiplayer". A new card appears below and reflects the change.
9. Switch to Matcha, then reload. The theme persists with no flash.
10. With the keyboard open on each phone, the prompt stays directly above it the whole time.
[ ] iPhone — Safari
[ ] Android — Chrome
[ ] Desktop — Chrome 1440 px
Any failed step becomes a new criterion in the milestone it belongs to, and the gate is run again.
