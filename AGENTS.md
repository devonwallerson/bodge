# Instructions for coding agents working on Bodge

Read [docs/IMPLEMENTATION_HANDOFF.md](docs/IMPLEMENTATION_HANDOFF.md), [docs/FEASIBILITY.md](docs/FEASIBILITY.md), [docs/QUESTION_BANK.md](docs/QUESTION_BANK.md), and [docs/ACCEPTANCE_CRITERIA.md](docs/ACCEPTANCE_CRITERIA.md) before changing application code. The two PNG files in `docs/reference/design/` are the visual source of truth; inspect both images directly.

The repository currently contains plans and design references. Do not assume a Next.js app, API key, hosting connection, or end-user authentication already exists. Build the first milestone with mock ideas and no provider credentials. Work in the repository root and preserve the reference files and planning history.

Keep the app accountless in v1. Accepted ideas persist on the current device. Generate three useful ideas with a funny twist. The interview draws exactly five questions from the 50-question bank, one per coverage slot. Ask the owner to review the bank before declaring the interview milestone complete.

Update the acceptance checklist as milestones are verified. Keep credentials in ignored local files or host secrets. GitHub repository: `https://github.com/devonwallerson/bodge`.
